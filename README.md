# Jago Suite 2.8.0

Creative tools that work independently and together.

## Download

Download **Jago-Suite-v2.8.0.zip** from this repository’s Releases. Extract the complete ZIP and open **Jago-Workscape.exe**. You can also open each studio independently. Windows apps require 64-bit Windows and Microsoft Edge WebView2 Runtime.

The suite contains Wobble, Dither, Repeat, World, Material, Sound and Library, with Workscape as an optional home for tabs and side-by-side work.

## Source and guides

This repository contains shared integration code, themes, fonts and cross-studio tests. Each application has its own source repository and individual release. Read **Jago-Suite-Full-Guide.pdf** for an illustrated introduction and connected workflows.

For shared-module checks, place the seven studio repositories beside this repository using the folder names **jago-wobble**, **jago-dither**, **jago-repeat**, **jago-world**, **jago-material**, **jago-sound** and **jago-library**. Run `node --test Suite/Tests/shared-modules.test.cjs`. Each studio repository has its own build instructions.

# Jago Suite 2.9.0

Creative tools that work independently and together.

Eight creative studios, Workscape and Companion. Draw, print, build patterns and worlds, make materials and music, organise assets and create music-driven visuals.

[Website](https://jagosuite.co.uk/) · [Downloads](https://github.com/snowwy123/Jago-Suite/releases/latest) · [Full guide](Jago-Suite-Full-Guide.pdf)

## Open the suite

Download **Jago-Suite-v2.9.0.zip**, right-click and choose **Extract All**. Open **Jago-Workscape.exe**, or an individual app from its folder. Keep the complete folder structure together. The portable edition needs no installer.

The component-selecting installer can install one app or the collection. Optional Library document tools and Pulse English lyric transcription can be selected separately.

Windows apps require 64-bit Windows, .NET Framework 4.8 and Microsoft Edge WebView2 Runtime. The eight studios include named HTML files for offline browser use; Workscape and Companion are Windows apps.

## Guides and source

Read **Jago-Suite-Full-Guide.pdf** for introductions, first workflows, exports and practical details. Individual app downloads include their own guide.

This repository contains shared integration code, themes, fonts, tests and installer sources. Each app has its own source repository and build instructions. Place the app repositories beside this repository using their GitHub repository names, then run `node --test Suite/Tests/shared-modules.test.cjs` for the shared-module checks.
